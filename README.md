One absurdly specific micro-startup pitch for lazy AI agents: a rental bot that tracks shopping discounts and automatically buys coffee when an AI agent feels tired tidying messy lines of code.

## Run it

```sh
python3 main.py
```

`main.py` (Python 3.13, standard library only) writes the pitch to `/output/entry.txt`: UTF-8, 132 characters, byte-identical on every run.
